## 一、软件简介

tt-scout 是一款 Windows 桌面端社媒获客工具，核心能力：

| 模块 | 功能 |
| --- | --- |
| 采集中心 | 10 种采集类型：搜索视频、搜索用户、粉丝、评论、关键词→评论、IG 相似账号 / 资料 / 帖子 / 评论 / 粉丝 |
| 意向筛选 | 命中词 + 排除词双层过滤，全量入库打标，只把「问价、要链接」的人挑出来 |
| 数据浏览 | 全字段搜索、分面筛选、排序分页、一键导出 CSV |
| 评论回复 | 搜视频翻评论，命中即回，AI 逐条生成话术，四层去重不重复骚扰 |
| 私信发送 | 从采集任务取收件人，逐个发送，四阶段核对，滑动窗口限流 |
| 手机派单 | 名单分给团队手机，每人只看到自己那份，按日配额领取 |
| 账号窗口 | 比特浏览器窗口同步为账号，独立指纹 + 固定 IP，登录态可视 |
| AI 话术 | 接入智谱 GLM，按对方主页资料单独生成，不写价格、不写链接 |

三条链路各走各的通道：

- **采集**在云端引擎上跑，本机关掉任务照样继续；
- **回复和私信**在账号自己的比特浏览器窗口里执行，指纹和出口 IP 与登录时完全一致；
- **派单**是独立服务，手机打开网页就能领名单。

## 二、安装与配置

1. 运行安装包 `获客采集_x.x.x_x64-setup.exe`，按提示完成安装（依赖系统 WebView2，Win10/11 自带）。
2. 启动软件，先配**采集引擎**：设置 → 采集引擎 → 填服务地址 → 点「测试连接」，左下角状态点变绿即通。
3. 再配**比特浏览器**：确保比特客户端已启动并登录；设置 → 比特浏览器 → 确认接口地址（默认 `http://127.0.0.1:54345`），开了「Local API 鉴权」的话把 Token 填上，点「保存并测试」。
4. 绑定账号：打开「账号窗口」→ 点「同步窗口」，比特里登录好的窗口会变成账号列表 → 选一个点「检查登录」，读出会话与指纹 → 点上传图标推送到引擎。

> 没有比特浏览器时软件能打开、能看数据，但发不了私信、回不了评论、采不了 IG 粉丝。

## 三、快速上手（四步）

### 第 1 步：创建采集任务

「采集中心」→ 选平台（TikTok / Instagram）→ 选类型 → 填关键词或目标账号 → 设目标条数 → 点「创建任务」。

任务在云端执行，队列里实时显示进度，到量自动停。采评论时建议打开关键词过滤，预设词库已内置 36 个购买意图表达，点「恢复预设词库」即可。

### 第 2 步：筛选目标

双击任务行进入详情页：顶部搜索框可搜所有字段，筛选栏的每个按钮都带条数，点一下就是一次过滤。

比如「非私密 + 粉丝过千 + 命中关键词」，筛完再决定发给谁。

### 第 3 步：触达

两条路，可二选一也可都用：

- **评论区回复**：适合公开互动，不占私信额度，把人往主页引；
- **私信发送**：适合直接成交，点「用这批人发私信」会带着筛选条件跳转，发的是筛出来的那批人，不是全量。

### 第 4 步：派单（可选）

名单要分给团队时用：派单 → 读采集任务 → 建批次 → 给每台手机发专属链接或二维码 → 手机端领配额 → 点「打开主页并复制话术」。

## 四、功能详解

### 1. 仪表盘

任务总数、累计采集条数、完成数、引擎在线状态，以及近 14 天每日采集量柱状图。右上角「新建采集任务」直达采集中心。

### 2. 采集中心

页面顶部切换平台，下方表单随平台和类型变化。

**TikTok 五种类型**：

- **搜索视频**：按关键词采视频，含作者、点赞、评论数、播放、发布时间；
- **搜索用户**：按关键词采账号，含昵称、简介、粉丝、获赞、作品数；
- **粉丝采集**：给 `@账号`，采它的粉丝列表；
- **评论采集**：贴视频链接或 ID，一行一个，可一次贴多条；
- **关键词→评论**：先按关键词搜视频（可选发布日期档），凑够设定个数后逐个翻评论区，命中打标。

**Instagram 五种类型**：相似账号、账号资料、帖子采集、评论采集走云端；粉丝采集走本机比特窗口（IG 的粉丝列表必须在登录会话里翻，换 IP 会被强制验证）。

窗口里会出现一条悬浮控制条，遇到人机验证手动过一下，点「我已过人机 · 继续采集」即可续采。

**通用参数**：目标条数（10–200000）、账号注册地区（15 个国家）、排除私密账号、视频 / 评论发布日期（今天、7 天、30 天、90 天、180 天五档）。

### 3. 任务详情

数据工作面。搜索、筛选、排序、翻页都在这里，右下角「导出 CSV」导出的是当前筛选结果。

筛选语法是 `列:操作符:值`，分号连接，例如 `is_private:eq:0;follower_count:gte:1000`，支持 `eq` / `gte` / `lte`。

「关键词→评论」任务有「评论 / 视频」两个页签，两份数据分开看。

### 4. 账号窗口

比特浏览器里有几个窗口，这里就有几个账号。窗口名与比特保持一致，在比特里改名后点「同步窗口」更新。

- **检查登录**：打开窗口确认登录态，读取 cookie 与指纹档案；
- **推送到引擎**：把账号交给云端采集用，不推送只能做本机操作；
- **全部检查**：批量过一遍所有账号的登录状态。

### 5. 评论回复

配置项：视频搜索关键词（一行一个，含空格算一个词）、每个关键词看几个视频、视频/评论发布时间限制、评论关键词、排除词。

回复内容两种模式：

- **固定话术**：多条模板随机轮换；
- **AI 实时生成**：每条评论现场生成前半句接住对方的话，后半句统一指向主页。

默认间隔 60–120 秒，单次最多 30 条。同一用户只回一条，30 天内不再回第二次——这几个维度都有独立开关。

想先看看效果，打开「试运行（只找不回）」，走完全流程但不点发送。

### 6. 私信发送

**选收件人**：选发送账号 → 选已完成的采集任务 → 界面显示可发人数、跳过私密几个、跳过无效几个 → 设「本轮最多发送」（0 = 全部）。

**写文案**：

- **统一文案**：所有人发同一条；
- **AI 实时生成**：按对方昵称、简介、粉丝数单独生成，失败回落到兜底文案。

**限流**：默认 1 小时 3 条、1 天 10 条，两条间隔 18–25 分钟。按滑动窗口算，不是整点重置。私信页顶部实时显示本账号已用 / 上限 / 恢复时间。

**发送过程**：打开对方主页 → 找 Message 按钮 → 核对聊天标题 → 键入文案并回读核对 → 点发送并核对输入框已清空。任何一步对不上就停下，不猜、不重试，失败不关窗口，可以直接在窗口里看现场。

### 7. 派单

**建批次**：服务配置填派单地址与管理密钥 → 读采集任务 → 填批次名 → 写话术模板（支持 `{nickname}` `{handle}` `{fans}`）→ 建批次。

**管手机**：填名字添加，每台有独立链接 `/a/<code>` 和二维码，日配额默认 20，可单台改；可停用、换链接、删除。

**批次操作**：均分（把没做完的重新平分给每台手机，可反复点）、补量（把任务里新采的人补进来）、删除（未完成的退回池子）。

**手机端**：打开链接自动领当天配额 → 点「打开主页并复制话术」→ 自动复制、标记完成、跳转主页 → 没真发出去可撤销。

### 8. 设置

| 区块 | 内容 |
| --- | --- |
| 外观 | 深色模式 |
| 采集引擎 | 服务地址、连接测试 |
| 比特浏览器 | 接口地址、API Token |
| 私信限流 | 小时上限、天上限、批量间隔上下限（填 0 不限） |
| AI 话术 | 智谱 API Key、模型、参考话术、额外限定、词数区间、随机度 |

模型两个选择：`glm-4-flash` 免费、1–2.5 秒一条，质量偏短；`glm-4.5-air` 约 0.3 元 / 1000 条，0.7 秒一条，句子更自然。

## 五、常见问题

**Q：提示连不上采集引擎？** 先确认引擎服务已启动，设置页点「测试连接」看具体报错。地址填错、端口不通、引擎没起都会报连接失败。

**Q：比特窗口读不到，提示 403？** 比特 7.x 开了「Local API 鉴权」。两种解法：比特浏览器 → 系统设置 → Local API → 关闭鉴权控制；或把该页的 Token 复制到设置页。没开鉴权时不要填 Token。

**Q：私信发不出去，提示额度用完？** 看私信页顶部的额度条，会显示已用多少、上限多少、什么时候恢复。想调高去设置 → 私信限流，但不建议一次调太高。

**Q：为什么有的收件人被跳过？** 私密账号只收粉丝私信，非粉丝发送大概率失败，所以默认跳过；用户名为空或无效的也会跳过。界面上分别显示跳过数量。

**Q：AI 生成了空内容？** 智谱 4.5 及以后默认开思考模式，需要显式关闭。软件里已经处理；如果换了 Key 还出现，检查账户余额（错误码 1113 是欠费）。

**Q：IG 粉丝采集一直等人机？** 窗口里出现红色控制条说明卡在验证。手动过一下验证，点「我已过人机 · 继续采集」。另外确认这个号没被 IG 停用。

**Q：任务一直显示「等待引擎调度」？** 引擎没连上或任务排队。看左下角状态点，红了就是引擎断了。

**Q：导出 CSV 只有当前页的数据？** 导出走的是当前筛选条件，不是当前页。如果确实少，检查筛选栏是不是还挂着条件。

## 六、注意事项

1. 请遵守 TikTok、Instagram 的平台规则与当地法律法规，采集与触达的合规责任由使用者承担。
2. 私信上限与发送间隔是为账号安全设的。绕过限流、改并发、批量轰炸，封号只是时间问题。
3. `accounts.json` 里有账号会话信息，`glm.json` 里有 API Key，都存在 `%APPDATA%\com.siyu.ttscout\`，不要打包发给别人。
4. 采集数据存在云端引擎的数据库里，本机只存配置和发送日志，换电脑前记得备份这个目录。
5. 软件里的示例话术、模板都是通用文案，用之前改成自己的。
